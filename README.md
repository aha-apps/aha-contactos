# AHA Contactos

CRM manual companion para vendedores. Gestión de contactos offline-first.

## Perfil
- **Lite** — Dexie (IndexedDB) + CryptoJS
- **Target**: Vendedores, inmobiliarias, agentes de seguros, pymes

## Módulos
1. **Dashboard** — Stats cards + gráfico donut por etiqueta
2. **Contactos** — CRUD + búsqueda + badges etiqueta
3. **Historial** — Timeline interacciones por contacto
4. **Plantillas** — Grid tarjetas por categoría + copiar
5. **Recordatorios** — Lista con check completado + filtros

## Uso
Abre `index.html` en cualquier navegador moderno (doble clic).

## Stack
- Alpine.js + DaisyUI 4 + Tailwind Play CDN
- Dexie.js (IndexedDB)
- CryptoJS (cifrado notas)
- Chart.js (dashboard)
- Bootstrap Icons + Animate.css
